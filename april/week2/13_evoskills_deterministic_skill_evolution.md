# EvoSkills: Why AI Companies Are Shipping Deterministic Markdown Files Instead of Smarter Models

## 5 Intuitive Takeaways

1. **EvoSkills uses a student-tutor-oracle co-evolution loop to self-generate skill files without human intervention** — a "student" LLM writes code/skills, a "tutor" LLM generates increasingly difficult test suites to expose failures, and a ground-truth oracle (black-box, binary pass/fail) validates against reality. When the student aces the tutor's tests but fails the oracle, the tutor escalates test complexity — pushing the system out of local minima. This co-evolutionary pressure is what makes skills progressively more robust without any weight updates to the underlying LLM.

2. **The oracle's harsh binary feedback is the actual innovation — it forces the tutor to keep escalating** — the oracle gives zero explanation, just pass or fail. When a student scores 100% on practice tests but fails the real exam, the tutor is forced to acknowledge its tests were too easy and must generate harder, more edge-case-heavy evaluations. This feedback loop between tutor inadequacy and oracle reality is what drives genuine skill improvement rather than overfitting to weak tests.

3. **The uncomfortable insight: enterprise AI is converging on deterministic templates, not smarter neural networks** — the real revelation isn't the algorithm, it's the implication. AI companies are externalizing intelligence into skill markdown files and Python scripts because enterprises won't pay for probabilistic systems. A compliance officer can read a markdown workflow. A deterministic skill file executes the same way every time. The LLM is reduced to a linguistic router that selects the right template and feeds data into it.

4. **This only works for tasks with verifiable, code-executable reward signals — and that's a hard ceiling** — the entire co-evolution loop depends on an oracle that can programmatically verify outputs (correct CSV, valid code, matching F1 score). For open-ended qualitative tasks — creative writing, nuanced legal reasoning, ambiguous medical diagnosis — the mathematical loop collapses because there's no binary ground truth to force tutor escalation. The methodology's power is also its boundary.

5. **The endgame of applied AI may not be AGI — it may be using superintelligent models to mass-produce perfect deterministic software** — the strongest LLMs (Opus 4.6, GPT-5) are needed exactly once: to write the skill files. Those skill files can then be transplanted to cheaper, smaller models (Haiku, DeepSeek V3) that execute them with dramatically higher task performance. The economic logic is clear: train once at the frontier, deploy forever at commodity cost. The LLM becomes a skill compiler, not a runtime intelligence.
