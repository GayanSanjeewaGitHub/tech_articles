# The Routing Distraction: Why Vision MoE Models See Correctly But Think Wrongly

## 5 Intuitive Takeaways

- **The model correctly extracts visual information but still fails at reasoning — the blame isn't the vision encoder, it's the MoE router** — when a MoE model sees an image of "2 + 2 = ?", it correctly perceives the numbers and the operation. But the router, seeing pixels instead of text tokens, dispatches the data to visual processing experts instead of mathematical reasoning experts. The model "sees" the math problem perfectly but never "asks the math department for help." 73% of failures are reasoning errors, not perception errors.

- **Visual experts and reasoning experts are physically separated in the network — and visual tokens can't cross the gap** — in a 48-layer MoE model, visual-only experts cluster at the early and terminal layers, while math/reasoning experts cluster in the middle layers. The overlap is negligible. When visual input activates the early layers, it gets trapped in the visual expertise zone and fails to traverse into the mathematical reasoning zone in the middle. This is a structural flaw in how MoE layers are stacked and trained, not a data quality issue.

- **Cross-modal semantic alignment IS working — the model internally knows that a picture of "3" and the text "3" are the same thing** — the researchers proved this with a cross-modal intervention experiment showing an inverted U-shaped success pattern: low in early layers (features not yet aligned), peaking in middle layers (semantic sharing occurs), declining in terminal layers (output already determined). So the knowledge representation is shared, but the routing mechanism ignores this shared understanding and routes by modality anyway.

- **A soft routing intervention (nudging router logits by a small delta toward reasoning experts) fixes the problem — but only by ~2 percentage points** — by adding a small enhancement coefficient λ to the router's scoring for domain-relevant experts during inference, the model starts routing visual math problems to math experts. The fix works directionally, proving the routing distraction hypothesis. But the improvement is surprisingly small (e.g., 52.3% → 54.5%), suggesting that the routing problem is real but there are deeper architectural issues beyond just router bias that limit visual reasoning performance.

- **Jensen-Shannon Divergence between text and image routing paths is the diagnostic metric — and it gets worse as visual complexity increases** — JSD measures how differently the router treats the same semantic content when it arrives as text vs. image. As images become more complex (more visual noise around the same math problem), the JSD in middle layers increases and accuracy decreases. Higher JSD = more routing distraction = worse reasoning. This gives the field a concrete, measurable signal for diagnosing and potentially training against this failure mode in future MoE architectures.
